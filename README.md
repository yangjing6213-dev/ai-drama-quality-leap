# AI短剧质变Skill

帮助 AI 短剧创作者把剧本拆成更具体的表演、情绪和镜头提示词，让生成的人物更自然、镜头更有电影叙事感。

把剧本直接交给 AI，常见结果是人物表情僵硬、说话时嘴巴机械张合，镜头也缺少明确的叙事目的。AI 不是演员；想让角色像真人一样表演，需要把“怎么演”讲清楚。**AI短剧质变Skill**会把这些导演判断整理成逐镜头提示词，供你交给兼容的 AI 工具继续创作。

<a id="what"></a>
## 一、这个项目是什么？

这是一个供支持 **Agent Skills** 格式的 AI 智能体使用的 Skill。Skill 是一套让 AI 按特定方法完成任务的操作指南，需要放进支持它的工具中使用；它本身不是视频生成软件。

你提供短剧剧本、场景梗概、对白或故事节拍后，AI 会按 Skill 中的流程分析人物意图与情绪变化，再为镜头补充可见的表演动作、自然口型、运镜、焦距、对焦、景深和光线提示词。它主要帮助创作者回答：**这句台词应该怎么演，镜头怎样配合？**

<a id="example"></a>
## 二、先看效果

Skill 内置了一个文字示例（不是实际生成的视频或效果对比）：

**输入片段：**

> 她看完手机，抬眼对面那个人说：“原来你早就知道。”她没有哭，只把手机放在桌上。

**Skill 会整理出的方向：**

- 将“克制愤怒”作为主要表演方向，并把“失望”标为导演推断，而不是剧本事实。
- 写出眉心、目光、嘴唇、肩膀和停顿等观众能看到的细节。
- 设计以眼睛为焦点的中近景和缓慢推进，并提醒服装、位置和光线保持连续。
- 给出一段可以继续交给视频生成工具的完整提示词。

完整示例在 [`SKILL.md`](SKILL.md) 的“示例”部分。**仓库没有真实生成视频、截图或运行结果**，因此这里不展示虚构的成片效果。

<a id="audience"></a>
## 三、适合谁用？

### 特别适合

- 正在用 AI 视频工具制作短剧、剧情片段或角色对白镜头的创作者。
- 已有剧本或场景梗概，但不确定如何把情绪写成具体表演动作的人。
- 想让说话口型、无对白反应、镜头运动和人物外观更连贯的创作者。

### 不适合

- 希望这个仓库直接生成、剪辑或导出视频的人；它只指导 AI 生成镜头提示词。
- 需要 Skill 自动识别某个专有视频平台参数的人；目前没有针对某个生成器的专用适配。
- 尚未准备任何剧本、对白、人物或场景信息，却希望得到完全符合个人设想的成片的人。

使用时需要一个能读取 Skill 的 AI 智能体；真正生成视频还需要你自己选择的视频工具和相应账号。工具费用由所选服务决定。

<a id="outputs"></a>
## 四、你会得到什么？

一次使用后，AI 会在当前对话中给出可编辑的文字结果，通常包括：

- 场景节拍、人物意图、情绪类型与强度；
- 每个镜头的表情、视线、呼吸、姿态和动作节奏；
- 景别、主要运镜、焦距参考、对焦点和景深目标；
- 对白镜头的自然口型说明，以及可直接复制的视频提示词；
- 跨镜头人物、服装、动作方向、光线和位置的连续性提醒。

Skill 不会自动保存结果文件，也不会生成视频；你可以复制提示词到自己的创作工具中继续修改和生成。

<a id="value"></a>
## 五、它能帮你解决什么问题？

只给 AI 一段剧本，常常没有说明人物如何表现、什么时候停顿、视线落在哪里，也没有告诉镜头为什么移动。Skill 会把这些容易遗漏的决定逐镜头写出来，并把推断与剧本事实分开。

这能减少反复补充“表情自然一点”“镜头电影感一点”这类笼统要求。你仍需检查人物解读是否符合故事，并根据所用视频模型调整提示词；Skill 不保证模型一定按每项描述生成。

<a id="install"></a>
## 六、安装与快速开始

### 使用前准备

- 一个能加载 `SKILL.md` 文件的 AI 智能体。不同工具的 Skill 安装位置和启用方式可能不同。
- 如果还要生成视频，另需你选择的视频生成工具；此项目不包含视频服务或账号。
- 仓库本身只有 Markdown 文件，不要求安装代码依赖。使用 AI 服务是否收费，取决于你选用的服务。

### 推荐安装方式：Codex（Windows）

先确认电脑已安装 Node.js 22.20 或更高版本，然后打开 PowerShell，把下面一整行复制并运行：

    $env:DO_NOT_TRACK='1'; npx --yes skills add yangjing6213-dev/ai-drama-quality-leap --skill ai-drama-quality-leap --global --agent codex --yes

命令会将 Skill 安装到当前用户的 Codex 全局目录。DO_NOT_TRACK=1 会关闭安装工具的匿名使用数据与安全审计请求。完整的安装说明、排查方法和可复制的剧本输入示例请看 [USAGE.md](USAGE.md)。

如果你使用其他支持 Skill 的智能体，可按其工具名称将命令中的 --agent codex 替换为相应名称；支持范围以安装工具的官方文档为准。

### 第一次试用

在新的 Codex 对话中复制下面的指令，并把方括号内容替换成自己的剧本：

```text
$ai-drama-quality-leap
请根据下面的短剧片段设计逐镜头表演和视频提示词。区分剧本事实与导演推断，重点处理情绪变化、自然说话口型、镜头运动和跨镜头连续性。

剧本：
[粘贴你的场景、对白和动作]
```

结果会显示在当前对话中。先检查情绪判断和镜头设计，再要求 AI 按你的意见修改；复制最终提示词到视频生成工具后，才会进入视频制作环节。

<a id="usage"></a>
## 七、如何使用？

1. **唤起并给出材料：** 在 Codex 新对话输入“$ai-drama-quality-leap”，再粘贴完整场景或剧本片段，尽可能保留台词前后的动作和剧情背景。
2. **说明目标：** 例如希望表演克制、突出对话中的迟疑，或让镜头更多观察听者反应。
3. **检查逐镜头结果：** 看看情绪是否有剧情依据，人物动作是否合理，口型说明是否对应台词，镜头是否保持连续。
4. **继续调整：** 指出需要修改的镜头、情绪强度或画面目标，让 AI 只改相关部分。
5. **复制并生成：** 把确认后的提示词放入你选用的视频工具；按生成结果继续人工调整。

可直接补充：“第 2 个镜头把情绪降到 2 级，保留停顿，改为固定机位；不要新增台词或动作。”

<a id="workflow"></a>
## 八、项目工作流程

```text
提供剧本 → AI 梳理剧情节拍与情绪 → 设计表演和镜头 → 输出完整提示词 → 你检查并交给视频工具生成
```

AI 负责依照 Skill 组织提示词；你负责确认导演判断、角色设定和最终画面。是否生成以及如何保存成片，由你使用的视频工具决定。

<a id="notes"></a>
## 十、注意事项与常见问题

- **人物仍像在“干瞪眼”：** 可能是剧本信息不足，或生成模型没有执行表情细节。补充台词前后的动作和人物意图，并把每个镜头的主要表演动作写清楚。
- **嘴型不跟台词：** Skill 会提示自然口型，但无法代替视频模型的语音同步能力。提供音频通常更利于对齐；没有音频时，台词节奏只是估计。
- **焦距、光圈不生效：** 它们是画面参考，不保证每种模型都模拟真实镜头。应同时描述人物大小、对焦位置和背景清晰范围。
- **剧本或人物解读有偏差：** AI 的情绪和潜台词判断可能是推断。请以剧本为准，修改或删除不符合故事的部分。
- **隐私与费用：** 剧本可能包含未公开创作内容。提交前请查看所用 AI 服务的数据处理和隐私选项；模型与视频工具费用由各自服务决定。
- **许可证：** 本仓库原创文件采用 [MIT 许可](https://github.com/yangjing6213-dev/ai-drama-quality-leap/blob/main/LICENSE)。它不授予小红书笔记、教程视频、第三方商标或其他外部素材的使用权；来源与范围见 [SOURCES.md](SOURCES.md)。
- **参考来源：** 项目作者提供的教程笔记仅作为学习和研究参考。仓库中的例句与提示词已重新编写，没有附带教程视频、字幕或逐字提示词。
